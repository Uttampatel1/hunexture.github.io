# Interactive AI lab

> Hands-on 3D visual explainers of the maths behind the AI we ship: vectors, matrices, loss functions, gradient descent, logistic regression and probability.

Canonical URL: https://hunexture.com/lab/

## Experiments

- **[3D Vector Representation](https://hunexture.com/lab/3d-vector-representation/)**: Interactive 3D visualization of vectors in three-dimensional space. Understand vector components and their geometric representation.
- **[3D Dot Product](https://hunexture.com/lab/3d-dot-product/)**: Explore the dot product of vectors in 3D space. Visualize how the angle between vectors affects their dot product.
- **[Matrix Transformation](https://hunexture.com/lab/matrix-transformation/)**: Discover how matrices transform vectors in 3D space. Experiment with different transformation matrices and see the results in real-time.
- **[Loss Function Visualizer (MSE)](https://hunexture.com/lab/loss-function-mse/)**: Understand Mean Squared Error through interactive 3D loss landscape and 2D regression visualization. Adjust parameters to minimize the error.
- **[Gradient Descent Visualizer](https://hunexture.com/lab/gradient-descent/)**: Watch gradient descent in action! See how the algorithm automatically finds the minimum of the loss function by following the gradient downhill.
- **[Gradient Descent 3D (Normalization)](https://hunexture.com/lab/gradient-descent-3d/)**: Advanced gradient descent visualization showing the critical importance of data normalization. Toggle between normalized and unnormalized data to see the dramatic effects!
- **[Conditional Probability 3D](https://hunexture.com/lab/conditional-probability-3d/)**: Understand conditional probability P(A|B) through an interactive 3D particle system. Step through the logic of restricting sample spaces.
- **[3D Logistic Regression Explorer](https://hunexture.com/lab/logistic-regression-3d/)**: Explore logistic regression in 3D! See how the sigmoid function creates a decision boundary. Compare linear vs sigmoid modes and understand why logistic regression works for classification.
