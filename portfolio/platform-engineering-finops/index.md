# Kubernetes Platform and FinOps Dashboard

> Internal platform with self-service environments and cloud cost visibility per team.

Canonical URL: https://hunexture.com/portfolio/platform-engineering-finops/

This is an illustrative example project. Any metrics shown on the site are illustrative, not verified client results.

## Overview

A platform engineering setup on Kubernetes with GitOps deployments, standard service templates and a cost dashboard that shows spend by team and service.

## Challenge

Each team deployed differently, environments took days to request, and nobody could say which services drove the cloud bill.

## Solution

We shipped a golden-path template, Terraform modules, Argo CD for GitOps and tagging rules feeding a cost dashboard with budgets and alerts.
